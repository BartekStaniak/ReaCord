## 2. Description of Service

ReaCord is an open-source native C++ REAPER DAW extension (`reaper_reacord`) designed to connect REAPER with the official Discord desktop client using local Inter-Process Communication (IPC).

ReaCord enables users to display their current REAPER activity, playback state, project name, elapsed time, and track metrics as a Discord Rich Presence status on their personal Discord user profile.
